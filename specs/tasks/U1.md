## Backend additions
- `GET /me` → `{handle, role, display_name}` of the demo user.
- `GET /teams` → teams the user belongs to, each with `members: [{handle, display_name}]`.
- `GET /packs` rows gain `team_name` and `latest_run`: `null` or `{id, status, created_at, counts}` where `counts` maps finding status → number, from the pack's most recent run.
- `POST /packs` with the same company (case-insensitive, trimmed) and year as an existing pack → 409 `duplicate_pack` with `pack_id` of the existing one; serialised with an advisory lock so two requests cannot both pass.
