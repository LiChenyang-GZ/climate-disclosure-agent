# T28 · Keep the model's judgement when the code overrides it

- **Model**: — (Claude Code writes it)
- **Tier**: normal
- **Depends on**: T11, T27
- **Goal**: when the worker ends a check as `needs_review` although the model submitted a valid `submit_finding` (step / token cap, failed quote verification, too few searches for "no evidence"), the model's status is thrown away (note 13, items 20 and 42). Store it so review, the report and later evaluation can see what the model would have said.
- **Design**: `02-design.md` §7; decisions D12, D30, D58, D88
- **Libraries**: none new

## Decisions (D88)
- Migration `0011_proposed_status`: `findings.proposed_status text NULL`, check constraint: NULL or one of `evidence_found`, `partial_evidence`, `no_evidence_found`, `inconsistent`.
- `WorkerResult.proposed_status: str | None = None`. `_finish` sets it to the last parsed submission's status when the final status is `needs_review` and that submission exists; otherwise NULL. Method B and LC go through `_finish` too, so the rule is the same.
- Stored by `store_finding`; returned by the findings API, MCP `get_findings` and the JSON / CSV export (columns flow through). The Markdown export shows `Needs review (model: Partial evidence)` in the Status cell when it is set.
- Status, scoring and the review flow do not change: `proposed_status` is information, not a status.

## Failing tests to write first
1. Forced last step, model submits `partial_evidence` with verified quotes → `needs_review` / `cap_hit`, `proposed_status = partial_evidence`
2. `no_evidence_found` with too few searches → `insufficient_search`, `proposed_status = no_evidence_found`
3. Quotes fail verification twice → `quote_verification_failed`, `proposed_status` = the submitted status
4. Cap hit while the model calls a search tool (no submission ever) → `proposed_status` NULL; normal accepted finding → NULL; `error` / `not_checked` → NULL
5. The value is stored and returned by `GET /runs/{id}/findings` and `GET /findings/{id}`; Markdown export wording
6. The check constraint rejects `needs_review`
