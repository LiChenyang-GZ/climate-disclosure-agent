## Models (`models.py`)
All models: Pydantic v2, `model_config = ConfigDict(extra="forbid", frozen=True)`.

- `Pillar`: `Literal["governance", "strategy", "risk_management", "metrics_targets", "asic_review"]`
- `DocumentKind`: `Literal["sustainability", "annual", "other"]` (same values as `documents.kind`)
- `InconsistencyType`: `Literal["T1", "T2", "T3", "T4", "T5"]` (T6 is pack-level, never attached to a check)
- `Source`: `standard: str`, `references: list[str]` (min 1), `asic: str | None = None`, `law: str | None = None`
- `Relief`: `id: str` (snake_case, `^[a-z][a-z0-9_]*$`), `description: str` (non-empty)
- `FactSpec`: `name: str` (snake_case), `unit: str`, `description: str`
- `Check`: `id` (`^[GSRMA][0-9]$`), `title`, `pillar`, `source`, `requirement`, `counts_as_evidence: list[str]` (min 1), `does_not_count: list[str]` (min 1), `allowed_reliefs: list[Relief]`, `facts: list[FactSpec]`, `preferred_documents: list[DocumentKind]` (min 1, no duplicates), `queries: list[str]` (2–3 items, non-empty, no duplicates after normalisation), `cross_document: bool`, `inconsistency_types: list[InconsistencyType]`, `min_searches: int | None = None` (≥ 1 when set). All strings stripped and non-empty.
- `Defaults`: `min_searches: int` (≥ 1)
- `CheckSet`: `version: str` (non-empty), `defaults: Defaults`, `checks: list[Check]`, `sha256: str` (set by the loader, not read from YAML). Methods:
  - `get(check_id: str) -> Check` — raises `KeyError` naming the id
  - `ids() -> list[str]` in file order
  - `min_searches_for(check_id: str) -> int` — the check's override, else `defaults.min_searches`

Query normalisation for the duplicate test: lower case, collapse runs of whitespace, strip — the same rule D58 uses. Put it in `models.py` as `normalise_query(text: str) -> str` so T08/T11 reuse it.

## Loader (`loader.py`)
- `REQUIRED_CHECK_IDS = ("G1","G2","S1","S2","S3","S4","S5","R1","M1","M2","M3","A1","A2","A3","A4")`
- `load_check_set(path: Path | None = None) -> CheckSet`: default path is the packaged `checks.yaml` (via `importlib.resources`, so it works from an installed wheel). Reads bytes, computes SHA-256 of the raw bytes, `yaml.safe_load`, validates.
- Set-level rules (raise `CheckSetError`, a `ValueError` subclass, with a message that names the offending check id or field):
  - check ids are unique
  - the set of ids equals `REQUIRED_CHECK_IDS` exactly (report missing and unexpected ids)
  - relief ids are unique within a check; fact names are unique within a check
  - if `cross_document` is false, `inconsistency_types` must be empty
- Pydantic `ValidationError` and YAML errors are wrapped in `CheckSetError` (keep the original as `__cause__`); file not found → `CheckSetError` naming the path.
- `@functools.cache` on a `default_check_set()` helper that loads the packaged file once.

5. Each of these YAML variants (written to `tmp_path`, built by mutating a copy of the packaged data) → `CheckSetError` whose message contains the stated text:
   - duplicate id `G1` → `G1`
   - missing `A4` → `A4`
   - extra id `Z1` → `Z1` (also fails the id pattern; either message is fine as long as it names `Z1`)
   - unknown field `foo` on a check → `foo`
   - `queries` with 1 item, and with 4 items → `queries`
   - two queries equal after normalisation (`"Scope 1"`, `"  scope   1 "`) → `queries`
   - `min_searches: 0` → `min_searches`
   - `preferred_documents: [pdf]` → `preferred_documents`
   - `inconsistency_types: [T6]` → `inconsistency_types`
   - `cross_document: false` with `inconsistency_types: [T1]` → the check id
   - duplicate relief id within a check → the relief id
   - empty `requirement` (`"   "`) → `requirement`
   - invalid YAML (`"checks: [\n"`) → `CheckSetError`
   - non-existent path → the path
6. `normalise_query("  Scenario   ANALYSIS ") == "scenario analysis"`
7. Changing one character in a copied file changes `sha256`
