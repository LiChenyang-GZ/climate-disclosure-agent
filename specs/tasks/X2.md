# X2 · Import from OneDrive / SharePoint

- **Model**: — (Claude Code helper agent writes it; Claude reviews)
- **Tier**: normal
- **Depends on**: U2, X1
- **Goal**: a lead connects a Microsoft account, imports .pdf / .docx / .xlsx files from OneDrive or a SharePoint site into a pack, and later re-syncs changed files. Tested against recorded Microsoft Graph responses; a real tenant comes later (Christy, 27 Oct).
- **Design**: `02-design.md` §4, §5, §11, §11.1; decisions D52, D80, D81, D84
- **Libraries**: none new (`httpx` is already a dependency)

## Decisions (D84)
- Sign-in uses the **device-code flow** (no redirect URI on localhost): `POST https://login.microsoftonline.com/{tenant}/oauth2/v2.0/devicecode`, then poll `/token`. Scopes `Files.Read.All Sites.Read.All offline_access User.Read` (read only). Settings: `CDA_MS_CLIENT_ID` (required to connect), `CDA_MS_TENANT` (default `organizations`).
- Tokens live **in API memory per demo user** (`app.state`), never in the database or logs. An API restart or an expired refresh token → "Your Microsoft connection expired. Reconnect."
- Imported files go through **the same path as uploads** (size limit, 20-file limit, duplicate by sha256, `pack_parsing`, X1 parsers). Refactor the body of `upload_document` into a shared function rather than copying it.
- Each imported document records its origin: migration `0008_document_source` adds `documents.source jsonb NULL` = `{provider: "microsoft", drive_id, item_id, path, etag, web_url}` (null for uploads). Revision id `0008_document_source`, `down_revision = "0007_run_scope"`.
- Re-sync compares each imported document's `etag` with Graph. Changed → on **Update**, download the new version and ingest it as a **new document** (units are immutable, D52), then soft-delete the old one; past runs keep their evidence. Removed in Graph → mark only (`"Removed in SharePoint"`), never delete.

## API (all lead-only except status; 403 for alex)
- `GET /integrations/microsoft` → `{configured, connected, account}` (account = UPN).
- `POST /integrations/microsoft/device-code` → `{user_code, verification_uri, expires_in, interval}`; `POST /integrations/microsoft/poll` → `{state: pending|connected|cancelled|expired}` (`authorization_declined` → cancelled, `expired_token` → expired).
- `DELETE /integrations/microsoft` → disconnect.
- `GET /integrations/microsoft/browse?site_id=&drive_id=&item_id=` → `{sites:[…]}` at the root (OneDrive "My files" + `GET /sites?search=*`), otherwise folders and files with only supported files listed (`.pdf .docx .xlsx`). 401 from Graph → 409 `microsoft_expired`.
- `POST /packs/{id}/import` body `{items:[{drive_id, item_id, kind}]}` → per item `{item_id, status: imported|duplicate|denied|failed|rejected, error?, document?}`; Graph 403 → `denied` ("Access denied in SharePoint"); parser errors as for upload.
- `GET /packs/{id}/sync` → `{changed:[…], removed:[…], unchanged: n}`; `POST /packs/{id}/sync` body `{document_ids:[…]}` → re-imports those; pack goes back to Uploaded.
- Pack detail documents include `source` (path and provider) so the UI shows it.

## Graph calls (wrap in `src/cda/integrations/graph.py`, injectable `httpx.AsyncClient` / transport)
`GET /me`, `GET /me/drive/root/children`, `GET /sites?search=*`, `GET /sites/{id}/drives`, `GET /drives/{d}/items/{i}/children`, `GET /drives/{d}/items/{i}` (etag, deleted → 404), `GET /drives/{d}/items/{i}/content` (follows 302). Handle paging (`@odata.nextLink`) and 429 `Retry-After` (one retry).

## Web
- Pack page (lead only): **Connect Microsoft** → panel with the code and link, polling until connected → "Connected as …"; cancelled → "Microsoft connection was cancelled."; expired → "Your Microsoft connection expired. Reconnect." + Reconnect.
- **Import from SharePoint** dialog: browse sites / drives / folders, tick files (only supported ones shown), choose type per file → Import; per-file results ("Access denied in SharePoint", "Skipped 1 duplicate file"); empty folder → "No supported files in this folder."
- Document table: a Source column ("SharePoint · /Shared Documents/Drafts/x.pdf" or "Upload").
- **Re-sync** (only when the pack has imported files): "Everything is up to date." / list of changed files + **Update** / "Removed in SharePoint" marks.
