# T26 · Split two-page spreads before detecting tables

- **Model**: sol
- **Tier**: normal
- **Depends on**: T04 (spreads, D70), T05 (tables) — merged
- **Goal**: On a two-page spread, a table detected across the whole landscape page must not stop the page from being split into left and right halves. Found in T23 on CBA's 2026 annual report: on PDF pages 52, 70 and 71 (printed 100/101, 136/137, 138/139, financed-emissions tables) `find_tables` returns one table spanning both printed pages, so `page_areas` sees a block crossing the middle, treats the page as one page, and the two printed pages' text is interleaved line by line.
- **Design**: `02-design.md` §5 (Two-page spreads, tables); decisions D33, D52, D70
- **Libraries**: pymupdf (already used)

## Files
Only these may be created or changed:
- `src/cda/parsing/layout.py`, `src/cda/parsing/pdf.py`, `src/cda/parsing/tables.py`
- `tests/parsing/test_parsing.py`, `tests/parsing/test_tables.py` (and helpers in `tests/parsing/` if needed)

## Change
1. **Decide the spread from text only.** A page is a spread when `width / height >= 1.3`, no **text** block crosses the middle (as today, ±2 pt), and no text block intersects a central gutter band of ±1 % of the page width around the middle. Detected tables are **not** used for this decision.
2. **Detect tables per half on spreads.** On a spread, run table detection separately on the left and right half (`page.find_tables(clip=<half rect>)`), so a table can never span both halves; each table belongs to the half it was found in. Non-spread pages detect tables on the whole page, exactly as today.
3. The rest is unchanged: text blocks covered by a table are dropped, margins, printed pages and reading order work per half as today.
4. Bump the parser version string from `cda-parse-2` to `cda-parse-3` (D52: stored units record which parser produced them).

## Failing tests to write first (synthetic PDFs built with pymupdf in the test, like the existing helpers; no real-company PDFs, they are not in git)
1. Spread with a ruled grid drawn across the full page width (continuous horizontal rules from the left printed page to the right one, as in CBA), table cells with text on both halves, an empty gutter, and a page number at the bottom of each half → the page is split; every table unit has `page_half` `left` or `right`; no table contains cell text from both halves; all left-half units come before right-half units in reading order; printed pages are read per half.
2. Landscape single page (w/h ≈ 1.41) with one full-width table that has a text cell over the middle of the page → not split (`page_half` None), one table with all its cells.
3. Landscape single page with a body paragraph running across the middle → not split (as today).
4. Spread where text comes within the ±1 % gutter band but does not cross the middle → not split.
5. Existing spread tests (`test_spread_detection`, `test_spread_pdf`, `test_spread_table`, `test_repeated_body_and_half_isolation`) still pass; update `test_spread_detection` only for a changed function signature, never its expectations.
6. The parser version is `cda-parse-3/...`.
