# T01 · Docker Compose, database session and Alembic

- **Model**: luna
- **Tier**: normal
- **Depends on**: T00
- **Goal**: `docker compose up` starts Postgres with pgvector, the API and a placeholder worker; Alembic migrations run against it; tests get a throwaway Postgres from testcontainers.
- **Design**: `02-design.md` §1 (stack), §2 (architecture), §3 (package layout), §14 (testing rules); decisions D8, D43
- **Libraries**: sqlalchemy[asyncio], asyncpg, alembic; dev: pytest-asyncio, testcontainers[postgres]

## Files
Only these may be created or changed:
- `pyproject.toml`, `uv.lock` (add the libraries above; set `asyncio_mode = "auto"` for pytest; register a `db` marker)
- `.env.example` (add a commented compose example for `DATABASE_URL`; no real secrets)
- `Dockerfile` (one image for api and worker: `python:3.12-slim`, uv copied from `ghcr.io/astral-sh/uv`, `uv sync --frozen --no-dev`, non-root user)
- `.dockerignore`
- `docker-compose.yml`:
  - `db`: image `pgvector/pgvector:pg16`, user/password/db `cda`, named volume, `pg_isready` healthcheck, port 5432 published to localhost only
  - `api`: built from `Dockerfile`, `uvicorn cda.api.app:app --host 0.0.0.0 --port 8000`, port 8000, `DATABASE_URL=postgresql+asyncpg://cda:cda@db:5432/cda`, `depends_on: db: condition: service_healthy`
  - `worker`: same image, `python -m cda.runner.main`, same env and depends_on, `mem_limit: 2g` (D49 memory cap)
  - a one-shot `migrate` service (`alembic upgrade head`) that `api` and `worker` depend on with `condition: service_completed_successfully`
- `alembic.ini` (script_location `src/cda/db/migrations`)
- `src/cda/db/__init__.py`
- `src/cda/db/models.py` (`class Base(DeclarativeBase)` only; no tables yet — T02 adds them)
- `src/cda/db/session.py`:
  - `def make_engine(url: str | None = None) -> AsyncEngine` — uses `url`, else `Settings().database_url`; raises `RuntimeError("DATABASE_URL is not set")` if neither is set
  - `def make_sessionmaker(engine: AsyncEngine) -> async_sessionmaker[AsyncSession]` (`expire_on_commit=False`)
- `src/cda/db/migrations/env.py`, `script.py.mako`, `versions/0001_enable_pgvector.py`:
  - async env.py (asyncpg). URL: `config.get_main_option("sqlalchemy.url")` if set, otherwise `Settings().database_url`; clear error if neither. `target_metadata = Base.metadata`
  - `0001`: upgrade `CREATE EXTENSION IF NOT EXISTS vector`; downgrade `DROP EXTENSION IF EXISTS vector`
- `src/cda/runner/__init__.py`, `src/cda/runner/main.py`: placeholder worker. `main()` logs `"worker started"`, then loops logging `"worker idle"` every 30 s until SIGTERM/SIGINT, then logs `"worker stopped"` and exits 0. Make the interval and the stop signal injectable so a test can run it in under a second. T14 replaces the body.
- `tests/conftest.py`: session-scoped fixture `pg_url` that starts `PostgresContainer("pgvector/pgvector:pg16", driver="asyncpg")` and yields its async URL. Tests that need it are marked `db`. If Docker is not reachable: skip with reason "Docker not available" — **unless** env `CDA_REQUIRE_DOCKER=1`, in which case fail. CI sets that variable.
- `tests/db/__init__.py`, `tests/db/test_migrations.py`, `tests/db/test_session.py`, `tests/runner/__init__.py`, `tests/runner/test_main.py`, `tests/test_compose.py`

## Failing tests to write first
1. `make_engine()` with no argument and no `DATABASE_URL` in the environment → `RuntimeError` whose message names `DATABASE_URL`
2. `make_engine(pg_url)` + session runs `SELECT 1` → 1 (db)
3. `alembic upgrade head` (run through `alembic.command` with `sqlalchemy.url` set to `pg_url`) → `pg_extension` contains `vector`; a `vector(3)` column can be created in a temp table (db)
4. `alembic downgrade base` after upgrade → `vector` extension gone; `upgrade head` again succeeds (db)
5. `alembic upgrade head` twice in a row → second run is a no-op, no error (db)
6. Worker `main` with a 0.01 s interval and a stop event set after a few ticks → returns 0 and logged `worker started`, at least one `worker idle`, `worker stopped`
7. `tests/test_compose.py` parses `docker-compose.yml` with `yaml.safe_load` (PyYAML may be added as a dev dependency for this) and asserts: services `db`, `migrate`, `api`, `worker` exist; `db` image is `pgvector/pgvector:pg16`; `api` and `worker` depend on `db` being healthy and `migrate` having completed; no service sets `OPENAI_API_KEY` to a literal value
8. Existing `tests/test_health.py` still passes
