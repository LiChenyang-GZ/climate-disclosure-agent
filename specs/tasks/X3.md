## Decisions (D85)
- OAuth **client credentials flow** of a Salesforce connected app: `POST {instance_url}/services/oauth2/token` with `grant_type=client_credentials`. Settings `CDA_SF_INSTANCE_URL`, `CDA_SF_CLIENT_ID`, `CDA_SF_CLIENT_SECRET` (secret as `SecretStr`); the settings form can override them **in API memory** (never stored in the database or logged). API version `v62.0`.
- A pack's linked Account and the Cases created are stored: migration `0008_salesforce` adds `packs.salesforce_account jsonb NULL` (`{id, name}`) and table `salesforce_cases` (id, finding_id unique FK, case_id, case_number, created_at). Revision id `0008_salesforce`, `down_revision = "0007_run_scope"` (if X2's `0008_document_source` merges first, Claude rechains this one at merge time).
- Push is **idempotent per finding**: findings that already have a `salesforce_cases` row are skipped. Eligible findings: `inconsistent`, `partial_evidence`, `no_evidence_found` (latest review applied if any).
- Case fields: `Subject` = "<check_id> · <check title>" (≤ 255), `Description` = status, rationale, evidence locations and quotes (plain text, quotes marked as quotes), report link `/runs/{id}/report`; `AccountId`; `Origin` = "Climate Disclosure Agent".

## API (lead-only except GET; 403 for alex)
- `GET /integrations/salesforce` → `{configured, instance_url, edition}` (no secrets).
- `POST /integrations/salesforce/test` body `{instance_url, client_id, client_secret}` → 200 `{connected: true, edition}` or 422 `salesforce_rejected` ("Salesforce rejected the credentials."); on success keep them in memory.
- `GET /integrations/salesforce/accounts?q=` → SOQL `SELECT Id, Name FROM Account WHERE Name LIKE '%q%' LIMIT 10` with the term escaped (quotes, backslashes, `%`, `_`).
- `PUT /packs/{id}/salesforce-account` `{id, name}` / `DELETE` → link / unlink.
- `GET /runs/{id}/salesforce/cases` → per eligible finding `{finding_id, check_id, case_id?, case_number?, case_url?}` and `{ready: bool, reason?: not_configured|not_linked|nothing_to_send}`.
- `POST /runs/{id}/salesforce/cases` → creates the missing Cases; per finding `created|exists|failed` with error; `REQUEST_LIMIT_EXCEEDED` (403) or HTTP 429 → stop, 503 `salesforce_limit` for the rest ("Salesforce API limit reached. Try again later."); 401 → refresh token once, then 409 `salesforce_rejected`.
