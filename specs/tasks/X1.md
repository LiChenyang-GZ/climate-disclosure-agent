## Locator ("page") for non-PDF files
Units need `pdf_page >= 1`; Word and Excel have no fixed pages.
- `.docx`: page = top-level section number. It starts at 1 and goes up at each heading of the document's highest heading level (Title / Heading 1 …) once content has been seen. `page_count` = number of sections. `printed_page` = null.
- `.xlsx`: page = sheet number (1-based, workbook order, hidden sheets skipped). `printed_page` = sheet name, so evidence shows where it is. `page_count` = number of visible sheets.
- Sustainability page ranges (parts) stay PDF-only in the UI; the API keeps validating ranges against `page_count`.

## Parsing rules
- `.docx`: body paragraphs and tables in document order (`iter_inner_content`). Heading styles (`Title`, `Heading 1–3+`) become sections; other paragraphs go through the existing sentence packing. Tables: first row is the header (empty header cells → "Column N"), merged cells counted once, empty rows dropped, tables with fewer than 2 rows or columns kept as paragraphs.
- `.xlsx`: values (`data_only=True`, cached formula results), one section per sheet named after the sheet, then the sheet's used range as tables of at most 50 data rows, each repeating the header (first non-empty row). Numbers rendered without float noise (`1200.0` → `1200`, dates ISO). Limit 20,000 non-empty cells per workbook → `too_large`.
- Both reuse `build_units` unchanged by building the same `Block` / `TableData` inputs the PDF parser builds (headings carry larger font sizes by level).
- Errors: not a zip / corrupt → `invalid_file`; password-protected (OLE container) → `encrypted`; no text at all → `empty_document`; over limit → `too_large`.
- Parser version: `cda-office-1/python-docx-<v>` and `cda-office-1/openpyxl-<v>`. The PDF string `cda-parse-4/...` and `pdf.py`, `units.py`, `layout.py`, `tables.py` are not changed.

## API
- Upload accepts PDF (`%PDF-`), `.docx` and `.xlsx` (zip + extension); anything else → 415 `unsupported_format`. Stored as `<sha256>.<ext>`; PDFs keep `<sha256>.pdf`.
- `GET …/file` serves the right media type; Office files as attachment.

## Web
- File picker and checks accept `.pdf`, `.docx`, `.xlsx`; "Reading file…"; page-range inputs only for PDFs; new error texts: `encrypted` "Password protected", `invalid_file` "Couldn't read this file", `empty_document` "No text found in this file", `too_large` "Too large to read (max 20,000 cells)".
- Document table: "N sections" / "N sheets" instead of pages for Office files.
