## Parsing pipeline (`parsing/`)
`parse_pdf(path, *, max_pages=600, page_timeout_s=10.0, clock=time.monotonic) -> ParsedDocument` (sync, pure apart from reading the file). `ParsedDocument`: `sha256`, `page_count`, `parser_version`, `units: list[ParsedUnit]` in reading order. `ParsedUnit`: `key` (local, e.g. `p12L-3`), `parent_key | None`, `kind` (`section` | `paragraph`), `pdf_page` (1-based), `page_half` (`left` | `right` | None), `printed_page | None`, `section_path`, `text`, `token_count`.

`parser_version` = `f"cda-parse-1/pymupdf-{pymupdf.VersionBind}"`.

**`pdf.py` — open and limits (D49).** `ParseError(code, page=None)` with codes `invalid_pdf`, `encrypted`, `too_many_pages` (checked before reading any page), `no_text_layer` (no page yields any text; no OCR), `page_timeout` (a page took longer than `page_timeout_s` by the injected clock; checked after each page). Memory caps stay in Docker, not here.

**`layout.py` — pure functions on a `Block` dataclass** (`x0, y0, x1, y1, text, font_size, bold`), built from `page.get_text("dict")` (one block per PyMuPDF text block; `font_size` = size with most characters, `bold` = most characters bold). Keep the functions independent of PyMuPDF so most tests can feed `Block` lists directly.
1. *Spread detection (D70)*: a page is a spread when `width / height >= 1.3` **and** no block crosses the centre line (`x0 < mid - 2 and x1 > mid + 2`). Blocks go to the half containing their centre; all left-half blocks are read before any right-half block; each half is then laid out like a page of its own. Non-spread pages have `page_half = None`.
2. *Columns (D32)*: within a page or half, ignore blocks wider than 60 % of the area ("full-width"). If the remaining blocks leave a vertical gap ≥ 18 pt that lies between 30 % and 70 % of the area width, there are two columns. Full-width blocks split the area into horizontal bands; within each band read the left column top-to-bottom, then the right. Otherwise sort by `y0`, then `x0`.
3. *Header/footer (D32)*: margin = top or bottom 8 % of page height. Mask a margin block's text (lower case, every digit run → `#`, collapse whitespace). A masked text that occurs at the same position (`y0` rounded to 10 pt, same half) on more than half of the pages is dropped everywhere. Documents with fewer than 3 pages drop nothing.
4. *Printed page (D31, D70)*: per page (or half), take the first margin block whose stripped text is a bare number, `Page N`, or a lower-case roman numeral (`i`–`xl`), or a dropped recurring block whose masked text has exactly one `#`; its number is `printed_page` (as text). Otherwise None. No guessing from neighbouring pages.
5. *Headings*: body size = font size with the most characters in the document. A block of ≤ 20 words that does not end with `.` is a heading if `font_size >= 1.15 × body` or (`bold` and ≤ 12 words). Heading levels: distinct heading sizes, largest = level 1, at most 3 levels (smaller sizes fold into level 3); a bold body-size heading is the deepest level.

**`units.py` — units (D5, D34).**
- Text: NFKC (fixes ligatures), remove soft hyphens (U+00AD); join lines with a space, except a line ending in `-` joins with no space and keeps the hyphen; collapse whitespace; strip. Blocks that end up empty make no unit.
- `count_tokens(text) = ceil(len(text.split()) * 4 / 3)` (no tokenizer dependency; T06 may revisit).
- Each heading → one `section` unit whose `text` is the heading; its parent is the enclosing section. `section_path` = heading texts joined with `" > "` (`""` before the first heading). Each other block → `paragraph` unit(s), parent = innermost section (None before the first heading).
- Paragraphs over 350 tokens split on sentence ends (`.`, `!`, `?` followed by whitespace and an upper-case letter, digit or opening quote/bracket), packing sentences greedily up to 350, no overlap. Never split after `e.g.`, `i.e.`, `etc.`, `No.`, `Mr.`, `Ms.`, `Dr.`, `St.`, `vs.`, `Inc.`, `Ltd.`, `Co.`, `Pty.`. A single sentence over 350 tokens splits on word boundaries.
- Paragraphs are not merged across pages, columns or halves (verification allows a quote to span the next unit, D17).
- Tables are not detected here (T05); their text comes out as ordinary blocks for now.

**`store.py` (async, `AsyncConnection`, SQLAlchemy Core).** `ingest_pdf(conn, *, pack_id, kind, path) -> UUID`: parse, insert the `documents` row (`filename` = basename, `sha256`, `page_count`, `parser_version`) and all units, parents before children with real `parent_id`s, inside `conn.begin_nested()` so a failure leaves nothing behind. `context_header` and `embedding` stay NULL (T06). Units are only ever inserted, never updated.

## Parts (`parsing/parts.py`, D69)
`parts.yaml` lives in `data/real/<company>/` and describes the PDFs in that folder:

```yaml
documents:
  - filename: annual-report-2026.pdf
    kind: annual                 # documents.kind
    parts:                       # optional; PDF page numbers, 1-based, inclusive (D70)
      - kind: sustainability
        first_pdf_page: 118
        last_pdf_page: 151
        label: Climate-related financial disclosures
  - filename: climate-data-pack-2026.pdf
    kind: other
```

- Pydantic models, `extra="forbid"`. `load_parts_file(path) -> PartsFile` rejects: unknown `kind`, `first_pdf_page < 1`, `last < first`, overlapping parts within one document (message names both ranges), duplicate filenames, a listed file that does not exist next to the YAML.
- `replace_parts(conn, document_id, parts)`: rejects any `last_pdf_page > documents.page_count` with `ValueError` before writing; otherwise deletes that document's parts and inserts the new ones (parts are configuration and may change; units do not).
- `resolve_part(parts, document_kind, pdf_page) -> ResolvedPart(kind, part_id | None, label | None)`: the part whose inclusive range contains the page; otherwise the document's own kind with `part_id = None`. This is the reference behaviour for the query-time SQL join T08 will write.
- `data/real/_example/parts.yaml`: the example above, with a comment that ranges are PDF pages, not printed pages.
