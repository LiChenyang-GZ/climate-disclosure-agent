## Migration 0004 — reading order (D75)
- `units.seq integer NOT NULL`, `ck_units_seq` (`seq >= 0`), unique constraint `uq_units_document_id_seq` on (`document_id`, `seq`). The migration adds the column without a default; if `units` already has rows it fails with a clear message ("re-parse required: units has rows without seq") instead of guessing an order.
- `CREATE OR REPLACE FUNCTION reject_unit_mutation()` adding `seq` to the immutable columns; downgrade restores the 0003 body exactly and drops the constraint and column.
- `store.ingest_pdf` sets `seq` = the unit's index in `parsed.units`. Models match the migration (`compare_metadata` stays empty).

## Envelope (`envelope.py`, D60)
Pydantic `ToolResult(ok: bool, category: "found"|"not_found"|"bad_args"|"timeout"|"forbidden", retryable: bool, message: str, data: dict)`; `ok` is true only for `found` and `not_found`. Constructors `found(data, message)`, `not_found(message, data={})`, `bad_args(message)`, `forbidden()`, `timeout()`. `message` is ≤ 300 chars, plain text for the model, and never contains a stack trace, SQL, file path, user id or exception text. `forbidden()` always says the same generic text.

## Context and dispatch (`context.py`, `registry.py`)
- `ToolContext(conn: AsyncConnection, user_id: UUID, pack_id: UUID, embedder: Embedder | None = None, timeout_s: float = 10.0)` plus a `Coverage` object owned by the context (one per check; nothing persists across checks, D14).
- `TOOLS: dict[str, ToolDef]` with each tool's `name`, `description`, Pydantic `args_model` (`extra="forbid"`, fields valid for OpenAI strict mode: optional fields are `X | None` with no default other than `None`), and the async handler. `semantic_search` is only listed by `tools_for(method)` when `method == "C"`.
- `async run_tool(ctx, name, raw_args: dict) -> ToolResult`: unknown tool → `bad_args`; args failing validation → `bad_args` with a short field-level message (no input echo); `semantic_search` without an embedder → `bad_args` ("not available"); handler exceeding `timeout_s` (`asyncio.wait_for`) → `timeout` with `retryable=True`; any other exception propagates (bugs must surface, not be hidden from tests).
- Tools never write to the database.

## Permissions (`permissions.py`, D29)
`visible_pack_clause(user_id)`: a SQLAlchemy condition that is true only when `packs.id` belongs to a team the user is a member of (`team_members`). **Every** SQL statement a tool runs joins `documents → packs → team_members` with that clause and `documents.deleted_at IS NULL` — no separate "check then query" step. If the pack is not visible to the user, every tool returns `forbidden()`; a unit, document or part id that does not exist **or** is not visible / not in the context's pack returns the same `not_found` (never reveals that it exists elsewhere).

## Parts at query time (`parts_sql.py`, D69)
Logical parts of a document:
- document without `document_parts` rows → one part: `part_id = str(document_id)`, `kind = documents.kind`, `label = None`, `ranges = [[1, page_count]]`;
- document with parts → one entry per `document_parts` row (`part_id = str(part.id)`, its kind, label, range) **plus**, if any pages fall outside every part, one rest part: `part_id = f"{document_id}:rest"`, `kind = documents.kind`, `label = "Rest of document"`, `ranges` = the uncovered page ranges.
- A unit's part: the `document_parts` row whose inclusive range contains `units.pdf_page`, otherwise the rest part (or the whole-document part). Implement it as a SQL expression (`LEFT JOIN document_parts … BETWEEN …`) and test it against `cda.parsing.parts.resolve_part` on the same data.

## Tools
**`list_documents()`** → `found` with `documents: [{document_id, filename, kind, page_count, parts: [{part_id, kind, label, ranges}]}]` ordered by filename; empty pack → `not_found`.

**`keyword_search(query, document_ids=None, part_ids=None, limit=None)`**, `query` 1–200 chars after strip, `limit` 1–10 (None → 10). Unknown / invisible `document_ids` or `part_ids` → `bad_args` listing how many were unknown (not which). Searches `paragraph` and `table_row` units only (D62) with `websearch_to_tsquery('english', query)` and `ts_rank_cd`, ordered by rank desc, then `seq`, then `id`. Each hit: `unit_id, document_id, filename, part_id, part_kind, part_label, kind, pdf_page, page_half, printed_page, section_path, snippet, rank`. `snippet` is a **verbatim substring** of the unit's `text`, ≤ 300 chars, containing the first matching word where one can be found (else the first 300 chars), with `…` added outside the substring only when cut. No hits → `not_found` with a message suggesting other terms.

**`semantic_search(query, document_ids=None, part_ids=None, limit=None)`**: same arguments, scope rules and hit shape, with `score` (1 − cosine distance) instead of `rank`; query embedded with `ctx.embedder.embed_query` in `asyncio.to_thread`; units without an embedding are skipped.

**`read_unit(unit_id, mode="unit", neighbours=0)`**, `mode` `unit`|`parent`, `neighbours` 0–2.
- `unit`: the unit itself plus up to `neighbours` child units (`paragraph`/`table_row`) before and after it in the same document by `seq`.
- `parent`: for a `table_row`, its `table` unit (Markdown); for a `paragraph`, its section: the `section` heading followed by that section's direct `paragraph`/`table` children in `seq` order; a unit without a parent → itself. `neighbours` is ignored in `parent` mode.
- Returns `found` with `units: [{unit_id, kind, pdf_page, page_half, printed_page, section_path, part_id, text}]` in `seq` order and `truncated: bool`. Total text is capped at 4,000 characters (D15): the requested unit (or the parent's first unit) is kept first; later units are dropped or cut, and the last kept text ends with `"\n[truncated]"`.

## Coverage and repeated queries (`context.py`, D58)
- Each `keyword_search` / `semantic_search` call records `(tool, normalised query, frozenset(part scope))`, where the query is normalised with `cda.checks.models.normalise_query` and the scope is the set of part ids searched (all parts of the pack when no filter is given; with `document_ids`, all parts of those documents; with `part_ids`, those parts; both given → the intersection).
- The same `(tool, normalised query, scope)` a second time → `bad_args` ("repeated query; try different terms or scope"), not executed and not counted.
- `Coverage.distinct_queries` (count of distinct normalised queries across both search tools), `Coverage.parts_covered` (union of scopes of executed searches, including searches with no hits), and `Coverage.missing_parts(all_part_ids)` for the D58 check in T11. `read_unit` does not add coverage.

## Failing tests to write first (strict: every case its own test, seen failing first)
Fixture: two teams, users `sarah` (team A) and `alex` (team B), a team-A pack with an annual report that has a sustainability part (pages 3–5) and rest pages 1–2 and 6, an `other` document without parts, a soft-deleted document, and a team-B pack; units inserted with `seq`, context headers and `HashEmbedder` embeddings.

Migration and store:
1. `upgrade head` → `units.seq` exists, NOT NULL, unique per document; `downgrade 0003_document_parts` → column gone, trigger body equals 0003's; `upgrade head` again works
2. `upgrade head` from 0003 with an existing unit row → fails with the "re-parse required" message
3. Updating a unit's `seq` → trigger error; two units with the same (`document_id`, `seq`) → `IntegrityError`
4. `ingest_pdf` → `seq` values are `0..n-1` in reading order

Envelope and dispatch:
5. Unknown tool → `bad_args`; extra argument → `bad_args`; `limit=11`, `limit=0`, empty / whitespace query, 201-char query, `neighbours=3`, `mode="page"` → `bad_args` each; messages contain no input values
6. A handler that sleeps past `timeout_s` → `timeout`, `retryable=True`
7. A handler raising `RuntimeError` → the exception propagates
8. `semantic_search` with no embedder → `bad_args`; `tools_for("A")` excludes it, `tools_for("C")` includes it
9. Every args model passes T07-style strictness: all fields required-or-nullable, `extra="forbid"` (assert on `model_json_schema()` directly; T07's helper is not imported)

Permissions:
10. `alex` calling each tool on sarah's pack → `forbidden` with the same message every time
11. `read_unit` on a team-B unit id, on a random uuid, and on a unit of another team-A pack → identical `not_found`
12. `keyword_search` with `document_ids` containing a team-B document → `bad_args` "1 unknown", no results leaked
13. Soft-deleted document: absent from `list_documents`, never in search hits, `read_unit` on its unit → `not_found`
14. A user removed from team A after the context was created → next call `forbidden` (the check is in the query, not cached)

Parts:
15. `list_documents` returns the annual report with three parts (rest 1–2 & 6 as one rest part with two ranges, sustainability 3–5) and the other document with one whole-document part
16. SQL part resolution equals `resolve_part` for every page 1–6, including both boundaries
17. A document whose parts cover every page has no rest part
18. `keyword_search(part_ids=[sustainability])` returns only units on pages 3–5; `part_ids=[rest]` only pages 1–2 and 6; unknown part id → `bad_args`
19. Changing a `document_parts` range changes the next search's part assignment without touching `units`

Search:
20. `keyword_search` ranks the unit mentioning the terms twice first; only `paragraph`/`table_row` units; ties broken by `seq`
21. Snippet is a verbatim substring of the unit text, ≤ 300 chars, and contains the matched word for a match in the middle of a 1,000-char paragraph
22. No hits → `not_found`, and the query still counts for coverage
23. `semantic_search` with `HashEmbedder` returns the same-text unit first with the highest `score`; unembedded units skipped; same scope rules as keyword search

Read:
24. `read_unit(mode="unit", neighbours=1)` returns previous, self, next by `seq`, skipping `section`/`table` units; at the first unit of a document there is no previous
25. `mode="parent"` on a `table_row` → the table Markdown; on a paragraph → section heading + the section's children in order; on a unit with no parent → itself
26. Long output → total text ≤ 4,000 chars, requested unit first, ends with `[truncated]`, `truncated=True`

Coverage:
27. Same query with different case/spacing and same scope a second time → `bad_args`, not counted; same query with a different scope → executed and counted
28. `distinct_queries` counts distinct normalised queries across both search tools
29. After searching with `document_ids=[annual]` only, `missing_parts` lists the other document's part; after a search with no filter, nothing is missing
30. `read_unit` calls do not change coverage
